## About

- I work on my company's internal operations platform, a growing set of modules built with Node.js, TypeScript, React and PostgreSQL. My work spans the database, APIs, interface and deployment.
- I build role-based access control, multi-step approval workflows, and email, WhatsApp and web push notifications.
- I'm building my Linux and networking skills by running a Debian home server with Immich, Jellyfin, Pi-hole and file sharing, published through Nginx and Cloudflare Tunnel.
- B.Tech in Computer Science and Engineering, Maharshi Dayanand University.
