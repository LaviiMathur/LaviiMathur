## About me

- 🏢 Sole engineer on my company's **internal ERP**: a Node.js/Express + TypeScript API and a React web app on PostgreSQL, used across four departments. I handle everything from schema and APIs to UI and deployment.
- 🔐 I build role and permission-based access control, JWT authentication, approval workflows, and email, web push and WhatsApp notifications.
- 🐧 I use Linux (Debian and Arch) every day, and my Hyprland setup is tuned to the way I work.
- 🏠 I run a **home server** on a static IP with Immich, Jellyfin, FileBrowser Quantum, Samba shares and Pi-hole for network-wide DNS. It's reachable over HTTPS through Nginx and Cloudflare Tunnel.
- 🎓 B.Tech in Computer Science and Engineering, Maharshi Dayanand University.
